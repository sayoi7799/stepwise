# 演示说明：怎么看到效果

给评委的三档路径，按你手上有多少时间选。

## 一、30 秒：什么都不用装

**打开 [`samples/sample.study.html`](../samples/sample.study.html)**（下载后双击，
用浏览器打开）。这是一本 EPUB 经过流水线处理后的成品，能直接看到：

- 生词黄色高亮，鼠标停上去显示拼音和 HSK 等级
- 页面底部**生词卡片**，鼠标移上去卡片翻面，背面是拼音、等级、它出现的那句原话
  和模型给的中文解释
- 页头一行给出结论：「已知词覆盖率 89.6% · 判定：偏难，建议先降级改写再读」

这个文件完全自包含：CSS 内联，不引任何外部资源，不联网也能看。

**注意**：静态文件里**点段落没有反应**。点击解释需要本机服务（见第二档）——
这不是缺陷，是因为模型调用必须走本机，key 不能进网页。页面里点不动时也会
给出这句提示。

## 二、3 分钟：自己跑一遍

```bash
# 1. 装 MoonBit 工具链（一条命令，Windows PowerShell）
irm https://cli.moonbitlang.com/install/powershell.ps1 | iex

# 2. 克隆并跑测试：113 个测试全部离线，不需要网络和密钥
git clone https://github.com/sayoi7799/stepwise
cd stepwise
moon test

# 3. 读一整本 EPUB，输出逐章体检表
moon run cmd/main -- analyze samples/sample.epub --level 2
```

第 3 条的预期输出：

```
# 我的中国朋友
- 章节数：2
- 已知词覆盖率：89.6%
- 生词：7 个（共出现 11 次）

## 逐章体检
| 章节 | 词数 | 覆盖率 | 判定 |
| 第一章 我有一个中国朋友 | 57 | 91.2% | 有点挑战，需要一点支撑 |
| 第二章 茶是一种语言 | 49 | 87.7% | 偏难，建议先降级改写再读 |
```

## 三、看交互：点一段，模型解释它

```bash
# 需要自备 DEEPSEEK_API_KEY；没有也能起服务，只是点段落不出解释
export DEEPSEEK_API_KEY=sk-...        # PowerShell: $env:DEEPSEEK_API_KEY = "sk-..."
moon run cmd/main -- serve samples/sample.epub --level 2
# 学习版已就绪：http://127.0.0.1:8787/
```

浏览器打开 `http://127.0.0.1:8787/`，**点正文里任意一段**。卡片从段落下面弹出，
上面有一排模式按钮，可以随时切换：

| 模式 | 拿到的 |
| --- | --- |
| 改成简单中文 | 用你水平以内的词重写这句话，附英文对照 |
| 逐词解释 | 这句话里每个超纲词在这句话里的意思 |
| 语法拆解 | 主干在哪、修饰挂在哪、有什么值得注意的句型 |
| 理解检查 | 一道理解题加参考答案 |
| 英文翻译 | 只要英文，作为意思上的锚 |

实测输出（`小明的家很近，走路只要十分钟。`）：

```
【改成简单中文】那个孩子的家不远，走路只要十分钟。
                Xiao Ming's home is very close; it only takes ten minutes to walk there.
                可读性审计：覆盖率 90.9%，仍有超纲词（钟）。
```

最后那行是重点：**模型给的改写也要过我们自己的可读性门槛**，不达标就带着
具体超纲词重做，最后的覆盖率如实告诉学习者。

> 服务是前台进程：终端窗口开着它才在跑，按 `Ctrl+C` 结束。关了窗口页面就打不开。

## 四、只有真模型那一步需要密钥

未配置 `DEEPSEEK_API_KEY` 时：

- `moon test`、`analyze`、`vocab`、`anki`、`prompt`、`html` **全部照常工作**
- `serve` 能起，页面能开、生词会高亮、卡片能翻面，只是点段落不出解释
- `explain` 会明确提示怎么设置变量，而不是崩溃

这是刻意的设计：模型调用被压缩成一个 trait，测试用脚本化假客户端，
所以 CI 和验收都不依赖外部服务。
